# 实验二 Shell 程序设计

## 实验目的与环境

通过 Bash 实验理解普通 Shell 变量和环境变量的继承、不同引号对展开的影响，并使用 `case`、`if`、循环及函数编写脚本。实验按《实验二 shell 程序设计实验》指导书完成。

实测环境为 Windows 上的 WSL 2，Ubuntu 24.04.1 LTS，GNU Bash 5.2.21。七个脚本均通过 `bash -n` 语法检查，完整终端输出见 [实测记录](实测记录.txt)。

## 变量与引号

运行 `bash 01-variables.sh`。在父 Shell 内赋值 `var1` 和 `var2`，只对 `var2` 执行 `export`。子 Bash 中 `var1` 为空、`var2` 显示 `I am a global variable`。回到父 Shell 后，两个变量仍保持各自的值。这说明 `export` 使变量进入子进程的环境，普通变量只保留在当前 Shell 中。

在含有 `alpha.txt`、`beta tool`、`run.sh` 等条目的目录中运行 [02-quotes.sh](02-quotes.sh)。`echo *` 与 `echo $var3` 都列出匹配的文件和目录。`echo "*"` 与 `echo "$var3"` 均输出 `*`。`echo '$var3'` 原样输出 `$var3`。反引号执行命令并取回它的标准输出，测试中 `var4` 保留了 `ls -l` 的多行结果。日常脚本也可使用便于嵌套的 `$(...)`。

## 程序设计与结果

| 题目 | 实现与实测 |
|---|---|
| [按时段问候](03-greeting.sh) | 用 `date +%H` 取得当前小时，再由 `case` 匹配时段。本次以本地时间运行，15 时输出 `Good afternoon!`。用可选小时参数覆盖 00、01、11、12、17、18、23 七个分界与邻近时刻。 |
| [比较两个整数](04-compare.sh) | 每行读一个整数并依次判断大于、小于或相等。`8` 和 `2`、`-3` 和 `0`、`7` 和 `7` 三组输入分别通过三个分支。 |
| [查找最小值](05-minimum.sh) | 从第一个数据开始，循环更新最小值。题给序列 `8 2 18 0 -3 87` 得到 `-3`，附加序列 `10008 10042 10006` 得到 `10006`。 |
| [统计可执行文件](06-count-executable.sh) | 逐项检查当前目录中的常规文件和可执行权限，覆盖隐藏文件与带空格的文件名。含 3 个可执行文件、1 个无执行权限的文件和 2 个子目录的样本得到 `3`，空目录得到 `0`。 |
| [函数判断素数](07-prime.sh) | 函数试除到平方根上界，由返回状态告知调用者是否为素数。`2`、`17` 和十进制 `029` 判为素数。`-5`、`0`、`1`、`4`、`25` 和 `009` 判为非素数，非整数参数以状态 `2` 退出。 |

在本目录可用以下命令复现代表性输入。计数脚本以调用时的当前目录为统计范围。

```bash
bash 01-variables.sh
bash 02-quotes.sh
bash 03-greeting.sh
printf '8\n2\n' | bash 04-compare.sh
bash 05-minimum.sh
bash 06-count-executable.sh
bash 07-prime.sh 17
```

## 问题与小结

- 指导书示例中的赋值语句需要去掉 `=` 两侧空格，Shell 注释用 `#`，变量名区分大小写。比较脚本始终使用同一组变量名。
- 判断可执行文件时同时检查 `-f` 和 `-x`。使用双引号或 Bash 的 `[[ ... ]]` 保留含空格的文件名，避免测试时统计到目录。
- 比较和试除都使用数值判断。最小值从实际输入初始化可覆盖较大的数据，素数判断先处理小于 `2` 的输入，再进入试除。
