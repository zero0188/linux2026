## 四、遇到的问题与解决办法

1. **`git clone` 连接 GitHub 超时（Failed to connect to github.com port 443）**
   - 原因：系统开启了本地代理 `127.0.0.1:7897`，浏览器走了代理，但 Git 默认不使用系统代理。
   - 解决：为 Git 指定代理后恢复正常。

     ```bash
     git config --global http.proxy http://127.0.0.1:7897
     git config --global https.proxy http://127.0.0.1:7897
     ```

2. **提交身份的作用域**
   - 为避免影响本机其他仓库，`user.name` / `user.email` 使用**仓库级别**配置（不加 `--global`），只对该课程仓库生效。

3. **Push 认证方式**
   - GitHub 已不再支持「用户名 + 密码」的命令行认证，需通过 Git Credential Manager 浏览器登录或 Personal Access Token 完成认证。
